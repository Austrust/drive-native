# .8 发布范围与已验证改善

本版固定本轮已经验证的提速和修复。按用户要求，发布后停止目标；未完成的目标与实验分支保留。

- **目录索引提速**：原版 FSearch 0.3.1，100,064 个文件＋2,066 个目录，三轮中位数首扫 170.16→78.77 秒，重扫 162.43→70.05 秒，耗时减少约 54%／57%。18 次扫描均核对完整，无漏项、重复或属性错误，未触发正文下载。对照为旧自建版；本地目录参考约 0.465 秒，尚未达到近本地体验，issue #5 保持开放。
- **队列恢复（#3）**：不确定提交按依赖隔离，独立操作继续；未知结果先只读核对，避免队首阻塞或盲目重复发送。本轮未重新检查或清理用户原有的 27 项队列。
- **文件时间（#4）**：支持普通文件 mtime 写回；真实原生会话验证 touch 和 cp -p。目录 mtime 仍不支持，时间为秒级，写回可能上传完整内容。
- **停止与升级（#1）**：保留停止恢复修复；实际暂停升级 schema22→23、旧后台切换及两份未上传修改保留通过。未重新运行原 Mint 故障现场。
- 初始化增加分阶段诊断、目录任务调度与数据库成本优化。真实 Lab 验证非空事件提交、未固定缓存后台更新，以及断网读取新版；这不代表 Personal_Sync 已完整初始化。

标准 Debian 构建：846 项 Rust、101 项 GUI 通过；另行显式运行 debug/release 各 25 项内核验证。安装在既有隔离 Ubuntu 24.04 环境验证，同版重装、卸载保留数据和重装读取通过；不是全新系统或 Mint 实机验收。

**仍是开发版**：Personal_Sync 完整初始化、普通目录全同步、持久历史（#2）、近本地 FS 性能（#5）、Mint 及最终数据安全／长期验收尚未完成。后续 FS 缓存实验存在安全边界和失败回归，目录等待实验尚无 NAS 验证；两者均未进入本包。不要清缓存来升级；数据库迁移后旧 ELF 会拒绝打开新 schema，不支持直接降级。
