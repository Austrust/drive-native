# Drive Native .20261113.1：P0/P1 缺陷收尾、剩余 open issues 验证与 #67 性能批

开发版 `0.1.0~dev20261113.1`，面向 Ubuntu 24.04／Mint 的后续试用。本版把上一批 draft PR #62–#66（#57–#61 修复）与后续两轮收尾（#23/#25–#28/#56/#6/#9 TB3，PR #68–#72、#79–#82）以及 #67 性能批（PR #73–#78、#83）全部合入 `main`，数据库 schema 保持 **29**、IPC 保持 **21**（本版无迁移）。FSD 与 worker 必须成对更新。

## 本次改善

- **#57（P0）命名空间派发饥饿**：pending 优先的派发路径 + durable `attempts` + 饥饿诊断；uncertain reconcile 不再独占单条提交 lane 把 pending 尾部永久冻结（本版修复合入 PR #62）。
- **#58 catch-up 预算与看门狗**：单次追赶会话有总墙钟预算，业务进展看门狗只认游标/事件推进，keep-alive 不能无限续期（PR #64）。
- **#59 FUSE 请求隔离**：可配置队列参数、按 opcode 的请求期限与有界 metadata 等待；慢 worker 不再放大为整挂载停顿，FUSE 隔离声明按实测机制校正（PR #66、#77）。
- **#60 存储生命周期上界**：cache limit 缺省值有界（min(10 GiB, 10% disk)，显式 0 仍可退出淘汰），孤儿 draft 隔离回收，迁移备份只保留最新两份/30 天（PR #63）。
- **#61 持久 pause 启动语义**：上一生命周期的 `sync_paused_v1` 在启动时自动恢复并清 flag，`paused_by` 报告来源；当前会话用户 pause 不受影响（PR #65）。
- **#9 TB3 诊断收口**：replace 准备阶段的未知回复由静默变为可见后台错误（自动重试、不写 commit 诊断）；namespace 调度观察保留同轮具体 reconcile 原因；不可能状态显式失败；新增 12 个运行时/核心测试钉死（PR #72，stacked 于 fixes4）。
- **#23 opendir 串行化残余**：目录投影的 single-flight 从「每挂载全局」改为「按目录」，并发打开不同目录不再互相阻塞；同目录仍共享一次投影；bench 无回归（PR #79）。按目录视图失效只交设计（见 `notes/design/`）。
- **#25–#28 可观测性与屏障成本**：status_cache 降级/恢复/预算越界进入产品 stderr/journald 诊断与 `health_snapshot()`；ACL 权限缓存与 READDIRPLUS 批量计数导出；invalidation 溢出/恢复发结构化健康事件；remove barrier 的 TEMP 版本触发器收窄到 `kind/state/node`，10k 混合积压端到端上传 ratio 从 6.7 降到 1.0、重建 8→1（PR #68–#71）。
- **#56 排除规则默认本地保留**：profile 新增 `exclude_mode: "local_only"（缺省） | "hidden"`。`local_only` 命中路径在挂载内**可见、可读写**，但不上传/下载/产生远端删除，未缓存正文读取返回 ENOENT；本地 write/create/mkdir/rename/unlink 完成后清理同步意图，正文受 GC/trim 保护；规则部分撤回不再需要清空全部规则（PR #82、#80）。**这是用户可见的默认行为变化**；显式 `"exclude_mode": "hidden"` 保持 #50 的完全隐藏语义。
- **#6 remove 冲突恢复**：`namespace_ops` 中处于 `conflict` 的原生 remove 新增 additive 恢复动作（GetIssues `can_abandon_remove` + D-Bus `AbandonRemoveConflict(id, token)`）：严格 CAS 门禁下恢复本地 tombstone、intent 置终态并写诊断，**绝不发送远端删除/修改 RPC**（PR #81）。
- **#67 性能批**：warm GetStates 复用一份已提交投影渲染；远端事件历史批量写并按 256 事件分块应用；状态投影常驻一份；GetIssues 首页事实与根页 cache 统计批量化；桌面轮询复用有界只读连接池；重叠的 cold GetStates 批合并为一次权威读（PR #73–#78、#83）。性能数字与未覆盖项以 issue #67 报告为准，本版不重复宣称。

## 行为变化与兼容

- **排除规则默认值**：旧 profile（无 `exclude_mode`）升级后从「完全隐藏」变为「本地保留、不同步」。若需要旧行为，显式设置 `"exclude_mode": "hidden"` 并重启该挂载；`docs/EXCLUDE_PATTERNS.md` 已按双模式更新。
- **#9 TB3**：replace 准备阶段的未知回复现在产生 `background_error` 并在下一轮自动重试；debug 构建在持久状态机违约时断言失败，release 构建返回显式错误。
- **#60**：未设置 cache limit 的 profile 不再「永不淘汰」，改为有界默认值；显式 0 仍表示禁用自动淘汰。
- **#61**：上一进程遗留的持久 pause 会在启动时自动恢复；这是对「重启后仍暂停」的修复，可能改变希望保持暂停的脚本预期。
- schema 仍为 29、IPC 仍为 21：本版没有迁移，升级不需要额外的 schema 备份步骤；但 FSD/worker 仍须成对更新。
- GUI 待办：排除模式选择控件未实现（保存规则会保留 `exclude_mode` 字段）；#6 恢复入口目前仅 D-Bus 可用。

## 实测结果

在 workstation202611（32 核／125 GiB，Rust 1.99.1）上，对合并后的 `main` 做干净重建并运行全量回归：

| 项目 | 结果 | 口径 |
|---|---:|---|
| `cargo test --workspace --all-features --locked` | **1439 通过 / 0 失败 / 85 忽略**（75 个 test result） | debug，与上一版 1322/0/67 相比 +117 passed/+18 ignored（均为新增测试） |
| `scripts/check-core-posix.sh` | 120 命中／66 文件／**0 violation**（120 allowlisted） | #11 门禁，无新增违规 |
| GUI 模块矩阵与打包测试 | 由 `dpkg-buildpackage` 的 `dh_auto_test` 执行（见打包日志） | 27 个 GUI 模块 |
| 内核 FUSE 套件（mounted／permissions_kernel／directory_views／readdirplus／namespace_index_kernel，显式 `--ignored` 串行） | **20 通过 / 0 失败**（10／5／1／2／2） | `DRIVE_NATIVE_FS_DIAGNOSTICS=1`，逐二进制串行 |

本批验证的边界：全部为合成夹具与 lab FUSE，未连接真实 NAS、未在真实 Mint／Cinnamon 桌面验收、未做真实 dpkg 安装/升级/卸载与 24h 长跑；真实 ACL 与 Personal_Sync 完整初始化门槛仍未通过。`local_only` 的完整 git 命令矩阵、规则变更重启矩阵与真实远端一致性验证留待真机复核。本包是开发版，不是 rc1。

## 升级说明

- 保存并关闭挂载内正在编辑的文件，暂停后安装；升级后 FSD/worker 成对切换，schema 不迁移、IPC 不升版。
- 升级后若需要旧的黑名单隐藏行为，在 profile 中加 `"exclude_mode": "hidden"` 并重启该挂载；否则命中排除规则的路径会重新可见但不同步。
- 详细 issue 状态与验证证据见 [RELEASE_NOTES.md](RELEASE_NOTES.md) 与本批内部报告（`notes/`）；候选包与源码归档的 SHA256 见发布资产 `SHA256SUMS`。
