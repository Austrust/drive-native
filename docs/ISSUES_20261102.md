# 停止恢复、多挂载界面与初始化修复

本批基于 `.6`，对应 [停止卡住 #1](https://github.com/Austrust/drive-native/issues/1) 和 [统一界面 #2](https://github.com/Austrust/drive-native/issues/2)。测试、包身份及交付状态以 [DELIVERY_GATES](../DELIVERY_GATES.md) 为准。

## 正常停止与升级

卸载路径后，已打开的文件或其他挂载命名空间仍可能引用 FUSE 会话。旧退出流程仅等待设备读取返回，存在无限等待的路径。后台会话现在使用独立本地唤醒通道，在卸载后结束接收循环；已分发的本地工作仍排空，未关闭草稿在退出前持久检查点保存。网络读取可取消，不把尚未完成的读取标为成功。

本地状态提供 `shutdown` 的阶段、总耗时、阶段耗时和超过 30 秒的提示。阶段包括停止网络工作、卸载、排空文件系统和保存本地状态。超时提供诊断，不默认强杀；`mounted` 在卸载后核对实际挂载表。暂停同步继续保留挂载，与停止挂载分别处理。

这修复的是已定位的退出协调路径，不能仅凭现场线程等待点断言所有历史故障具有相同根因。此前版本仍在运行时，其退出代码不会因安装新版而被替换；旧后台卡住需先完成原有恢复流程。

## 初始化期间保留已发现节点

父目录重新枚举发现同一子目录的时间或版本变化时，先核对文件身份、原生数值身份、名称、父目录和类型。全部一致则更新该目录的元数据并保留后代记录，重新标记整个受影响子树等待核对；身份替换、改名或类型改变仍走保守重建。

保留记录不代表保留旧授权或完成状态。原覆盖、未完成下载依据和目录票据仍须失效；明确拒绝访问的状态持续遮蔽，直到有效的后续列表确认。检查点只能在完整覆盖和事件核对成功后提交。重复失效已经 pending 且没有有效回执的目录，不再重写其覆盖行；检查点失效仍执行。

公开合成复放入口为 [initialization_directory_refresh_replay](../crates/drive-core/examples/initialization_directory_refresh_replay.rs)，使用临时本地状态和 10000 个后代。它分别报告记录保留、重新枚举工作量和耗时；不把合成事务速度作为真实 NAS 完整初始化速度。

## 统一界面首批范围

主窗口按挂载切换页面，后台仍各自独立。任务身份显式传入配置、服务和 D-Bus 接口，避免界面切换修改全局进程环境。会话级界面实例将后续启动请求转到已有窗口。托盘提供当前传输和任务操作；关闭窗口时托盘可用则保留入口，没有托盘时仍可从桌面重新打开，后台同步不受影响。

本批托盘内容是当前活动。后台持久历史、自动重试归并、历史文件按身份定位、完整全局暂停恢复和通知合并尚未交付；issue #2 继续开放。普通目录全量同步、初始化未完成时的正文按需读取，以及最终 Mint 和长期验收也保持原门槛。
