测试只创建并操作授权实验目录下的全新子树。没有修改真实个人文件、NAS权限或旧基线，也没有执行NAS清理。详细协议与服务器证据留本地；[SUMMARY.json](SUMMARY.json)仅含聚合、布尔核验及原结果哈希。

| 实际操作 | 核验结果 |
|---|---|
| 初始化取得水位后暂停，以独立原生会话创建实验文件，再恢复 | 同一候选及初始水位中找到对应非空事件页；应用序号1，候选ready、接收／应用／fence一致，权威检查点已提交 |
| 打开并缓存未固定的2MiB实验文件，以独立会话修改远端，随后不再打开挂载文件 | 后台取得新版本，核对本地完整内容、身份与版本；D-Bus状态为本地完整且未固定 |
| 回环透明转发器真正切断并拒绝客户端连接 | 从挂载路径读取新版内容成功；释放中断后恢复原生连接 |
| 在挂载中执行 `touch -m` 设置固定秒值 | 独立原生列表确认远端mtime准确、身份和内容不变，本地上传队列提交完成 |
| 在挂载中执行 `cp -p` 复制另一固定时间的文件 | 独立会话确认新身份、mtime、大小与内容，队列提交完成 |

文件时间验证包含真正的原生写回和独立读回，不只检查系统调用返回值。文件mtime精度为一秒，当前使用完整内容上传；目录mtime仍不支持，其他边界见[时间契约](../../FILE_TIMESTAMPS.md)。

这次小型实验验证了非空初始化事件和后台缓存保鲜闭环，不能代替Personal_Sync全树初始化、广泛冲突故障或长期稳定性。图标对应的D-Bus数据已核对，未把它算作Nemo视觉验收。运行与包测试／FS开发负载重叠，不作为配对性能结果。结束时工具对自己的无正文记录转发器发送SIGTERM（退出值-15），这是正常清理，不是FSD崩溃。
