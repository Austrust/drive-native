首次本包压测后正常停止超过105秒。准确符号栈与命名空间记录确认：WSL Pro服务在测试期间启动，继承了合成挂载副本；后台任务已退出，FUSE会话等待该副本释放。只对精确合成副本正常卸载后客户端退出0，没有强杀或操作原NAS挂载。该次仍记退出失败及环境干扰，不能计为自主停止通过。随后新实例重跑全部负载，自主停止0.120秒、退出0。客户端不自动卸载他人挂载命名空间。
