# P0：MFM 连接中断与退出行为基线

2026-10-31，WSL Ubuntu 24.04。使用未修改的 `.6`：源码 `62be13c9f9f4a2457a3040829f478bf43b1821df`，包 SHA-256 `4a66edf61d1a32f385f6f61f401db3c181b74f80df44cd0411140ae373c73cf4`。硬件、系统及运行文件身份见 [原始核验](../p0-baseline-audit.json)，本次范围见 [context.json](context.json)。NAS 版本沿用已有记录，本次未重新查询。

## 真实连接中断：30 次自动恢复，1 次超过 3 秒

将 MFM 协作（team 14）的 91,033 节点元数据以 SQLite backup 复制到全新隔离任务，仅复制完整缓存；确认没有待提交操作及脏内容。原六个挂载继续运行，没有重启或写入 NAS。隔离配置为只读，TLS 名称和 CA 校验保持原值。

隔离客户端经本机回环字节转发器连接 NAS。转发器不终止 TLS、不解析协议、不记录正文；每轮明确中断自己持有的前后端连接，保留监听器和 fsd。恢复判据是 worker PID 改变、重新接受连接且 GetOverview 返回 online（认证及恢复 pull 后）。这验证基本传输恢复，不证明远端版本或事件收敛。

预先登记 30 次、每次 15 秒截止、50 ms 状态轮询、轮间 0.5 秒；失败即停止且保留样本。每轮故障前打开已完整缓存的 1,001,486 字节文件并取得哈希，故障后立即通过同一句柄读取及枚举根目录。读取计时不包含此前打开和进程启动，目录计时包含 listdir。测量期间原六任务及两个观察探针继续运行，没有合成混合压测。连接重置没有模拟延迟、丢包或限速，不是网络吞吐实验。

| 项目（30 样本） | p50 | p95 | p99 / 最大 | 功能失败 |
|---|---:|---:|---:|---:|
| 中断到恢复 | 1.193 s | 2.264 s | 3.965 s | 0 |
| 预先打开的完整缓存读取 | 1.782 ms | 2.190 ms | 2.266 ms | 0 |
| 根目录枚举 | 4.532 ms | 5.284 ms | 5.551 ms | 0 |

零基 trial 24 超过 3 秒；不能因 p95 达到 3 秒就声明普通重连目标已通过。所有采样点 mounted 为 true，30 次内容哈希均与故障前打开版本一致。未测新打开句柄、缺失正文、持续断网、静默丢包、服务器重启、休眠或全部同步范围；不能替代 Personal_Sync 和培养的恢复验证。

证据：[预登记条件](relay/measurement-002/manifest.json)、[全部样本](relay/measurement-002/samples.jsonl)、[汇总](relay/measurement-002/summary.json)、[实际测量脚本](relay/runner.py)、[实际转发脚本](relay/byte-relay-executed.py)。脚本 LF 归一化哈希保存在 context.json。首次 `measurement-001` 在注入前因初始化 GetOverview 3 秒超时退出，保留为初始化问题；服务未重启，之后正常返回。它不计入 30 个连接恢复样本，也不被解释为注入失败。

隔离客户端在测试后 0.219 秒正常停止，再停止转发器，见 [退出结果](relay/stop-result.json)。状态数据保留，原六任务未停止。

## 无效注入及退出故障保留

最初尝试 `ss -K`，命令返回 0 但连接仍为 ESTAB，worker 未变化。对独立回环连接也出现同样现象；内核原因未确定。因此 [原始 result](invalid-injection/result.json) 中 `recovered=false` 不能归为客户端恢复失败，按 [判定说明](invalid-injection/adjudication.json) 标记为无效注入。改用自有转发器后才获得以上 30 次有效样本。通用转发工具另有本机回环集成测试，确认透明回传以及被控连接确实关闭；不是只检查命令退出码。

另建固定合成夹具，单独重跑 5 轮 mixed_held（240 个请求），目录 75 次超时，预先打开的缓存读取 p95 9.405 秒。随后服务 0.120 秒正常停止，见 [负载汇总](stop-repro/mixed-held/summary.json)、[退出结果](stop-repro/stop-result.json)。这次只运行之前七阶段负载的一个子集，**没有复现也没有修复**此前约 90 秒后被 systemd 强杀的问题；原失败记录继续保留。未取得当时线程栈，不推断具体卸载死锁原因。
