# Drive Native .20261118.1：首个实验性 RPM 包（Fedora 40+ / RHEL 10+）

开发版 `0.1.0~dev20261118.1`。本版**只改打包**：新增 `packaging/rpm/drive-native.spec` 与 `scripts/build-rpm.sh`，把项目首次带到 Fedora 40+/RHEL 10+（x86_64）。Rust 源码、数据库 schema（**29**）、IPC（**21**）、配置与运行时行为均无变化，也无迁移；`.deb` 版本随发布一起 bump，但载荷语义与 `.20261113.2` 相同。本版是开发包，不是 rc1。

## 本版变化

- **RPM 打包（预 staging 模式）**：`rpmbuild` 不编译任何东西；`%install` 复制 `scripts/build-linux.sh` + `scripts/stage-linux.sh` 产出的安装树（原生二进制、PyInstaller GUI、GIO 探针、桌面扩展、systemd 用户单元、文档），`.deb` 与 `.rpm` 共用同一条 staging 链，避免两套构建漂移。详见 [RPM_INTEGRATION.md](RPM_INTEGRATION.md)。
- **GIO 模块重定位**：构建机 Ubuntu 的模块路径是 `/usr/lib/x86_64-linux-gnu/gio/modules`，Fedora/RHEL 目标为 `/usr/lib64/gio/modules`；spec 与构建脚本都做重定位，`%post`/`%postun` 用 `gio-querymodules` 守卫刷新共享缓存，包内不携带 `giomodule.cache`。
- **systemd 用户单元只装不启用**：四个单元安装到 `/usr/lib/systemd/user/`，安装、升级、卸载都不启用、不启动；与 deb 的 `dh_installsystemduser` 覆盖语义一致，GUI 在账号配置完成后由用户显式启用。
- **GUI bundle 不 strip、不参与依赖扫描**：`__os_install_post` 置空、不生成 debuginfo；`%install` 只 strip 3 个原生二进制与 GIO 模块；PyInstaller bundle（私有 Qt/Python 运行时）被 `__requires_exclude_from`/`__provides_exclude_from` 排除，其系统库依赖在 spec 中显式声明：实测非 bundle 的只有 `mesa-libGL`/`mesa-libEGL`、`libdrm`、`libwayland-client/cursor/egl`、`libxcb`（bundle 自带 libX11/libxkbcommon/fontconfig/libdbus-1/xcb-util-* 等；deb 清单中的这些包仍作为桌面运行时契约保留声明）。
- **依赖映射**：原生二进制实测 NEEDED 仅 `libgcc_s`/`libm`/`libc`/`ld-linux`，对应 `glibc` + `libgcc`（并由 RPM 自动生成 soname capability）；显式 Requires 覆盖 `fuse3`、`glib2`、`systemd`、`ca-certificates`、`hicolor-icon-theme`、`python3-gobject`、`gvfs`/`gvfs-fuse`；`gnome-keyring`、`google-noto-sans-cjk-fonts`、`nemo-python`、`nautilus-python` 为弱依赖。完整映射表见 [RPM_INTEGRATION.md](RPM_INTEGRATION.md#5-依赖策略与-fedorarhel-映射)。
- **构建脚本**：`scripts/build-rpm.sh <输出目录>` 读取 `GUI_PYTHON`、`DRIVE_NATIVE_SOURCE_COMMIT`，校验 spec 与 `debian/changelog` 版本一致后构建、staging、重定位、`rpmbuild -bb`，并自检 NEVRA、内嵌 `SOURCE_COMMIT`/`BUILD_VERSION`、无 GUI bundle 依赖泄漏、无 Ubuntu multiarch 路径，最后打印 NEVRA + sha256。
- **文档与版本**：新增本文件与 `docs/RPM_INTEGRATION.md`，`docs/RELEASE_NOTES.md`、`README.md`、`debian/changelog` 同步；spec `%changelog` 记录首个 RPM 条目。

## 验证状态

本版源码树不修改运行时实现（相对 `.20261113.2` 发布提交只增加打包文件、文档与 changelog），因此缺陷与性能结论沿用 `.20261113.2` 的验证范围；`debian/rules` 的重建仍会按惯例运行完整 `cargo test` 与 GUI 回归门禁。RPM 包装配的具体结果：

| 项目 | 结果 |
|---|---|
| 共享 staging（`build-linux.sh` + `stage-linux.sh`） | 通过；322 文件 / 191.73 MiB（冷 target 约 44 s） |
| `rpmspec -P` spec 解析（rpm 4.18.2） | 通过：RC=0，stderr 0 行 |
| `rpmbuild -bb`（`scripts/build-rpm.sh`，gzip/9 对照） | 通过：`%install`/`%check` 全绿、无 unpackaged 文件；73,526,191 B |
| `rpmbuild -bb`（发布配置 `w19.xzdio`） | 通过：49,213,525 B（−33%）；`PAYLOADCOMPRESSOR=xz FLAGS=19`；`rpm -K` digests OK；`rpm2cpio | cpio -t` 692 条 |
| 依赖实测（`rpm -qpR`） | 自动依赖含 `libc.so.6(GLIBC_2.39)(64bit)`；显式 Requires 全部展开；无 bundled Qt/Python 依赖 |
| Fedora/RHEL 实机安装、升级、卸载 | **未验证** |
| RPM 签名、debuginfo、源 RPM、dnf 仓库 | 不提供 |

明确未验证项：真实 Fedora/RHEL 主机上的 dnf 事务、`rpm -V`、SELinux、Wayland/HiDPI 桌面与真实 NAS 端到端；GUI 系统库依赖按实测 ELF NEEDED（区分 bundle 自带与系统库）映射，而非逐个发行版实测安装。首次冒烟还发现并修复了 `scripts/build-rpm.sh` 封装层的两处自检误报（pipefail 下的 SIGPIPE、文件名误伤 multiarch 路径检查），详见 [RPM_INTEGRATION.md](RPM_INTEGRATION.md#81-冒烟中发现并修复的封装脚本问题)；最终发布构建使用修复后的脚本。`.rpm` 未签名，下载后请用发布资产 `SHA256SUMS` 校验。

## 升级说明

- 保存并关闭挂载内正在编辑的文件，暂停后安装新包；FSD/worker/GUI 必须成对切换。
- `.deb` 升级路径与之前相同：schema 仍为 29、IPC 仍为 21，本版无迁移、无需额外备份步骤。
- `.rpm` 为首次发布，无历史 RPM 版本可升级；首次安装不会启用任何用户 systemd 单元。
- 卸载不会删除用户配置、用户数据库、缓存或待写内容。

## 发布资产

每个发布包含源码归档、`.deb`、`.rpm`（Fedora 40+/RHEL 10+ x86_64）、`RELEASE_NOTES.md`、`SHA256SUMS`、`SOURCE_COMMIT` 与 `VALIDATION.json`。下载后先校验：

```sh
sha256sum -c SHA256SUMS
```

RPM 的 GitHub 资产名会把 `~` 规范化为 `.`（例如 `drive-native-0.1.0.dev20261118.1-1.x86_64.rpm`），内容与构建产物一致；版本以 `rpm -q --qf '%{NEVRA}\n'` 输出为准。
