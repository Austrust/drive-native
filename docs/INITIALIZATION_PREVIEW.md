2026-11-01，冷启动元数据预览已随开发包 `0.1.0~dev20261101.6` [发布](https://github.com/Austrust/drive-native/releases/tag/dev20261101.6)，冻结`7683b36dcbce91b5e6143ef17bb8e97882f0453b`，schema22／IPC18。[包验证011](validation/native-package-011/REPORT.md)记录743项Rust、75项GUI、debug／release各20项显式内核测试通过（各含7项新预览场景），以及隔离安装和迁移验收。独立Nemo／Nautilus回归各10项通过。此前[源码002](validation/progressive-preview-002/REPORT.md)及001失败保留为历史，不累加到包总数。本轮没有NAS首屏或配对性能验收。

## 用户可见行为

首次建立任务时，选定根通过原生身份核对后即可挂载。一个目录的完整直接列表持久接收，且其祖先覆盖仍有效时，可提前查看其中的名称和属性。目录浏览不下载文件正文，也不把候选数据写成权威节点。

| 状态 | 行为 |
| --- | --- |
| 根已验证、列表未完成 | 根可显示；展开返回暂不可用，不伪造空目录 |
| 直接列表完整接收 | 可浏览元数据，GUI／扩展显示初始化状态，不显示已同步或离线可用 |
| 子目录未枚举 | 父列表可显示该目录对象，进入时仍明确未就绪 |
| 权限拒绝 | 遮蔽相应子树并拒绝访问，不能解释为删除 |
| 普通文件 | 可显示名称和属性；全局ready前正文open暂不可用，写入及命名空间修改被拒绝 |
| 全局候选完成 | 保留原有身份、事件与fence验证，同事务转为权威树；新请求进入正常按需读写，无需重挂载 |

已有权威树的warm任务继续使用原目录、完整缓存和本地草稿，不将新候选与旧树拼接。暂停或网络worker退出不自动卸载；未被已知撤销的预览可继续浏览元数据。Linux文件管理器对暂不可用错误的具体提示需要实测，不承诺一定显示加载动画。

## 数据与权限边界

[core预览模块](../crates/drive-core/src/preview.rs)独立于通用Node、正文、草稿和命名空间写入接口。cold资格检查权威nodes、正式游标、草稿与操作日志等；缺失根而仍有旧状态的数据库不能进入预览。任务自身`drafts`目录采用不跟随符号链接的目录描述符，只检查首个目录项，不读正文或递归扫描；发现孤立草稿、异常目录或访问错误时阻止预览，保留文件。

权限拒绝以持久状态保留。目录从denied进入pending／loading不表示恢复授权，只有相同身份的有效列表接收后才能解除该目录拒绝；根拒绝需要已验证Root回执，普通根列表不能解除。普通Root复核等待不等于已知权限失效：候选root_refresh与预览可见性失效分别记录，允许未被撤销的旧预览在复核期间继续浏览。父目录成员可见代次随着子项拒绝／恢复更新，旧父目录句柄也必须失效。祖先失效会阻断后代访问。

[FUSE预览路由](../crates/drive-fs/src/preview.rs)只返回元数据，不创建候选正文句柄。create、mkdir、rename、unlink、setattr及写入路径必须取得权威身份；预览文件不会触发hydrator。挂载可以按profile使用RW选项，但预览权限及用户态门禁保持只读，TTL为0以便转正后重取属性。

## inode、目录续读与转正

预览使用现有单调inode分配器中的保留键，映射绑定run、file identity及同次原生列表返回的数值身份；不从文件ID推算数值身份。改名可以保留匹配inode，数值身份替换、run切换或同名替换不能复用旧对象。根在新run中可安全重绑，无需依赖GUI访问；旧句柄仍按原origin失效。

[目录视图](../crates/drive-fs/src/directory.rs)保留不可变成员列表和cookie。preview续读在同一Store锁内验证自身、祖先与成员撤销代次，再发送一个有界回复；失效返回ESTALE／EACCES，不更换旧数组。warm续读沿用原无Store锁路径，其已有句柄ACL边界没有在本批解决。

预览映射有条目和字节预算。最终安装在既有权威树、游标、ready事务中转换仍匹配的inode；冲突或预算失败整体回滚。成功后清理失效保留映射，不触碰文件正文，AUTOINCREMENT防止旧inode号码重新分配。旧preview目录句柄不能静默升级成另一代视图。

## 验证范围与后续工作

合成回归源码覆盖父／子拒绝、根撤销与恢复、无GUI重建、同名及数值身份替换、预算、转正失败回滚、孤立草稿、迁移和旧reader拒绝。002已显式执行FUSE内核场景并通过。001实际发现普通Root探测误屏蔽预览，已分离root_refresh与预览失效状态；旧kernel测试硬编码0644的umask假设改为比较实际源mode。001未运行到新preview target，不能计作新预览通过；原失败和002结果分别保留。历史 `.5` 安装或其他分支结果不替代本批检查。

仍待验证或实现：
