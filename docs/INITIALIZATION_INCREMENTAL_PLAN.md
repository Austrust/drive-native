# 按目录发布与持久初始化：后续实施边界

只读审查基准：`8daff4a04252deca363b01e7e0c529a1b7c1f442`，2026-11-01。本文件是技术计划，**下述按目录提前可见、持久初始化和相应门禁尚未实现**。本轮可信当前水位与局部收敛即使完成，仍只能在完整候选通过验证后使用现有全量安装器；它们不等于目录已可逐步发布。

## 最小可维护的数据与发布模型

先增加独立候选区，不把未完成恢复直接写成当前权威树。既有目录、缓存、草稿和操作日志继续保留；已知权限撤销仍须立即按现有规则阻断访问。

- **初始化运行**：持久保存 `run_id`、任务/协议版本、完整 scope（包括 view、根 ID 与规范路径）、restore identity、捕获边界 B、候选事件接收/应用位置、阶段、错误与预算。候选位置与产品的 committed cursor 分开，不能复用同一个字段。
- **目录任务**：按稳定目录 ID 和代次保存未枚举、加载中、列表已接收但未确认、已确认、权限拒绝、可重试失败。每条记录关联运行身份、父身份、列表完整性与核对边界；子目录存在不代表其内容已枚举。
- **候选节点与事件**：节点按 ID 保存，目录成员集合按已完成的一次列表代次保存；原生事件先完整持久接收，再归约或标记需重新列举的目录。重复批次幂等，错 run/旧代消息拒绝。部分目录中的缺项只影响候选成员关系，不能全域删除节点、清草稿或生成服务器删除。
- **全局完成**：所有待处理目录和相关事件已收敛到共同边界 C，图结构/权限/根身份验证通过，才能将完整候选提交为权威索引。权威树、received/committed cursor 和初始化 ready 状态应在同一最终事务切换；不是先写 C、后补目录。

跨重启续接前重新认证并核对 scope、restore 与根身份，确认 B 之后事件仍可续接。正在接收的目录不能沿未经证明稳定的 offset 直接继续；最小实现重列该目录，保留其他已接收候选，再重放期间事件并重新核对。游标失效、gap、恢复标记或预算溢出时丢弃/重建候选，保留既有权威数据及本地修改。

## FUSE 提前可见的最小安全语义

初期以**一个已核对完整的直接子项列表**作为发布单位，不直接暴露单页残缺列表。单个超大目录首页提前可见需要额外分页/负查询契约，另行验收。

| 目录状态 | 访问行为 |
| --- | --- |
| 未枚举、加载中、已接收未确认 | 可以显示已确认的目录对象；其子项查询不得返回伪空目录或缓存 ENOENT。通过有界异步请求安排枚举，超时返回明确暂不可用；GUI/Nemo 显示加载状态。 |
| 已确认 | 为新 opendir 建立该代稳定视图；已打开目录继续原有视图，更新后发内核属性/目录项失效通知。 |
| 权限拒绝 | 返回拒绝访问，遮蔽相应子树；它不是远端删除或“成功列出零项”。 |
| 失败/断线 | 已有确认目录和完整缓存仍可读取；未确认子树保持明确未就绪，不把错误转为空结果。 |

仅靠向主 nodes 表提前插入 root 无法实现这些语义：lookup、readdir、父链、同名替换、ACL 与属性查询都必须采用同一候选发布代次。恢复期间尤其需要区分旧权威视图和新候选，避免将两代路径拼在一起。

本地已有打开句柄和草稿持久保存应继续工作。依赖尚未确认命名空间的创建/替换/改名不能依据一次假 ENOENT 执行。最小首版在全局 ready 前阻止所有远端写回，并明确显示“初始化未完成，修改保存在本地”；重启后读取同一持久门禁。后续若按目录放开远端写入，需要同时证明源、目标、父链及条件版本已确认，不能仅检测源目录 ready。

## 本轮水位与局部收敛的完整性不变量

1. 当前数值水位 B 是扫描起点，不是已应用检查点。列表字符串 cursor、文件版本及对象 max 字段不能替代事件 sync_id。根当前状态与 B 的关系必须由协议核对，不能伪造版本令牌或凭路径接受同名替代根。
2. 事件连续覆盖 B 至最终 C；空页但位置前进仍须继续。倒退、静止位置携带事件、merge/rescan、范围/恢复身份变化必须显式处理，不能吞掉后继续声明完成。
3. 列表可能比某条扫描期间事件更新。不能把旧事件盲目覆盖到较新的已列节点；没有已验证版本排序规则时，用事件标记相关目录重新核对，比按数字大小猜测对象新旧更安全。
4. 移动同时涉及旧/新父目录、身份及同名桶；目录移动还影响后代路径。未知父链、移入范围、移出范围、同名替换和删除不能只更新事件给出的一个路径。临时孤儿或列表缺项不证明全域删除。
5. 重列只替换该目录候选代次；已列旧子项、后来发现的新父、权限拒绝与未完成分页不能相互覆盖成权威删除。最终仍验证唯一根、稳定身份、唯一有效名称、父目录存在、无环、深度/节点/字节预算。
6. 权限缺项不等于删除；本地创建、namespace overlay、dirty blob/draft、冲突、未确定提交和旧完整缓存保持现有保护。局部收敛不得绕过 `install_native_snapshot` 的 scope/restore/token/expected_cursor 校验。
7. 远端写回与最终候选安装不能交错破坏共同边界。连接被替换、暂停取消、旧 request 回调和预算退出不得发布半候选或推进 committed cursor。
8. 进度必须区分收到页面、目录列表完成、目录已核对、事件已追到边界和全局 ready。不能以页数增长掩盖反复重列同一目录；记录有界重试和明确无进展原因。

## 分批落地与验收

**本轮适合落地：可信水位、相关目录局部收敛和完整候选提交；不适合把按目录提前挂载作为顺手修改。** 后者至少同时涉及 IPC、数据库迁移、有效命名空间、FUSE 完整性状态、写回门禁与重启恢复。持久候选可先实现并验收续接收益，再开放提前可见；不能用进度条完成代替这两项。

后续必须覆盖：

- 暂停一个深层目录：根目录已确认后可浏览，该深层目录显示加载/暂不可用，绝不返回空完成；GUI 关闭及 worker 重启不丢已发布视图。
- 单目录每页边界中断、重复/迟到页、父目录改名、跨目录移动及同名替换；无错身份、重复路径或负查询缓存遗留。
- 中断发生在持久批次接收、目录确认、最终事务前/后；重启不跳过事件，不提前上传，不需要清缓存。
- 权限收回/恢复、根同名替换、restore/scope 改变、非零 merge/rescan、事件缺口和持续写入；保持数据并明确恢复或失败。
- 有 dirty 草稿、pending/uncertain 写入时开始恢复；缺项不删本地修改，不错误重建远端文件；释放缓存仍不发服务器删除。
- 分别记录首个确认目录、首次 readdir、完整索引及事件追平时间，禁止把本地合成目录延迟当作 NAS 初始化收益。

新增水位/收敛代码后的审阅顺序：先核对 B/C 来源与事件连续性，再审目录失效覆盖和混合新旧版本，最后核对最终安装事务、持久游标及写回门禁。只有保留上述不变量的完整候选才能进入现有发布路径。本文件未执行任何新测试、NAS 请求或基线操作。
