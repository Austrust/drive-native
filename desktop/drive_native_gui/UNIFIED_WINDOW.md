# 统一主窗口与托盘（issue #2）

当前开发实现将多挂载管理收敛到同一个主窗口，并通过 schema24 的历史记录提供持久活动查询。当前传输与目录发现不等于已完成同步；实现及独立验证状态见 [#5/#2 报告](../../docs/FIX_5_2_REPORT.md)。

## 界面与隔离

- `MountManager` 展示所有挂载；任务详情是按需创建的嵌入页。切换挂载复用页面，不启动新的 GUI 进程。添加挂载仍使用现有配置向导。
- 每页显式绑定配置 slot、D-Bus 服务、systemd unit 和向导；保存、归档、恢复配置均使用该 slot。开发启动也通过独立子进程环境指定实例，不修改 GUI 进程的环境变量。
- 总览与当前活动查询按任务合并在途请求。某任务无响应不会等待后再刷新其他任务。外部配置替换时丢弃旧页面、旧服务对象及迟到回复。本页“更换目录”成功归档配置后，只保留自身拥有的短暂配置空缺；向导取消恢复或确认新任务后保留该页，服务状态重新核对，不把外部删除／替换视为本页事务。
- 隐藏任务页沿用已有懒加载，不展开文件列表就不查询目录。证书、缓存、问题和带宽继续复用各任务的对话框。
- 字体、按钮、列表及明暗配色复用同一个主题函数。系统配色变化同步更新嵌入页。

### 所有挂载概览

- 表格列为：挂载名称、状态、同步活动、问题、远端目录、本地位置。同步活动来自 `GetTransfers` 的在途缓存（2 秒轮询、单飞合并，迟到的旧任务回复丢弃，最多保留 128 项）；没有在途传输时回退到最近一次 `GetOverview` 的 `pending_operations`，仍无则显示“无”。问题列优先使用 overview 的 `issue_count`，旧后台缺失该字段时才合并登录失效、需要处理、待确认操作、`download_errors`、`background_error`／`upload_block`；没有问题时显示“无”。总览尚未返回或状态暂不可用时显示“—”，不猜测数值。
- 概览底部显示在途传输摘要与前 8 行（挂载、文件、阶段、正文进度），超出时提示打开各挂载查看完整列表；没有在途传输时显示“当前没有正在传输的文件”。
- 行右键菜单提供打开管理、打开文件夹、暂停或恢复同步、停止此挂载并卸载…、同步历史；选中行时原有工具栏按钮保持可用。双击行仍打开对应的嵌入页。

### 全局设置

- 全局设置页是真实设置，不再是占位文字：桌面通知两个开关、同步历史保留说明与“打开同步历史”入口、关闭／退出行为和键盘说明。
- 设置写入配置根下的 `gui-settings.json`（`schema=1`），与任务 profile 分离；目录 0700、文件 0600、`O_NOFOLLOW`、临时文件加 `os.replace` 原子替换。损坏、权限不符或含未知 schema 的文件回退默认值，不阻止窗口启动。设置只保存布尔偏好，不保存账号、服务器或密码。

## 通知与全局设置

- `NotificationCenter` 接收每次 `GetOverview`：`connection == locked` 提示需要登录；`needs_attention` 或 `error` 提示需要处理；`background_error` 持续满 60 秒提示持续同步失败。同一挂载的同一类问题在一个 episode 内只通知一次，条件消失后重置；同一挂载同类问题 30 分钟内合并，不同挂载、不同类别不合并。
- 通知文本使用中性短文案并带挂载名，不包含服务器地址、账号或错误详情；点击通知激活对应挂载，窗口隐藏时先 `showNormal`。托盘不可用时改由 freedesktop D-Bus 系统通知投递（`org.freedesktop.Notifications`）；系统通知也不可用时只做状态记账、不发系统通知，主窗口横幅继续显示状态。
- 系统通知的 `Notify` 调用由 jeepney 按显式签名 `susssasa{sv}i` 发送（PySide6 无法产生规范要求的 `uint32` replaced-id，纯 QtDBus 会被严格实现的守护进程以 `InvalidArgs` 拒绝）；`ActionInvoked` 信号由 QtDBus 订阅，默认动作复用 `clicked(target)` 的定位目标。投递层把每个通知的守护进程 id 映射到触发它的挂载 slot（有界，最多 32 条），点击旧通知仍打开该通知自己的挂载；id 未知或已淘汰时回退到最近一次通知的目标。jeepney 缺失或会话总线不可用时后端报告不可用并回退，不影响 GUI 启动。
- 成功通知默认关闭。开启后每 30 秒对每个挂载轮询 `GetRecentActivity(limit 20)`，按挂载记录最大 id 作游标，只合并新增的 upload/download 成功项为“「挂载」已完成 N 项同步”，不逐个文件提示，也不把历史记录当作新成功。
- 全局设置变更立即持久化并更新通知中心；关闭成功通知会停止轮询并清空游标，重新开启从新的基线开始。

## 托盘与激活

左键切换活动面板；右键提供主窗口、当前活动与最近历史、各挂载文件夹、单挂载及全体暂停／恢复、单挂载“停止此挂载并卸载…”、全局设置和两种退出方式。托盘 `messageClicked` 没有通知 id，回退到最近一次通知的目标；freedesktop `ActionInvoked` 携带通知 id，按投递层记录的目标打开该通知对应的挂载。托盘菜单不重复网络请求。当前活动仍展示在途传输，持久完成记录通过独立历史 IPC 查询。

托盘图标按语义四态着色：空闲（✓）、传输（·）、暂停（‖）、需要处理（!），未收到概览前为未知（?）。优先级为“需要处理”>“连接或恢复”>“在途传输”>“暂停”>“待同步”。传输数与问题数与主窗口同源：在途数来自 `GetTransfers` 在途缓存，问题数来自 `issue_count`（缺失时才回退到旧字段）；未收到概览时提示“正在检查状态”，不显示健康状态；提示文本不使用“上传”措辞。暂停分“部分已暂停”和“全部已暂停”，全体恢复只恢复本轮全体暂停记录的任务。

关闭主窗口时，有托盘则隐藏界面，后台继续同步；托盘不可用时保留主窗口，并提示通过“退出界面，继续同步”退出，后台保持运行。运行中托盘消失会重新显示主窗口。活动面板使用实际托盘位置或鼠标位置，并限制在所在屏幕内。桌面不支持左键激活时仍可走右键菜单。

GUI 使用会话 D-Bus 服务按配置根隔离单实例。再次启动激活同一窗口，并可定位 `--task` 指定的挂载。启动阶段的激活请求暂存，窗口就绪后执行最后一次请求。会话 D-Bus 不可用时保留可见窗口，不宣称该环境具备单实例保证。

历史行绑定所属服务和记录 id，打开前重新解析当前文件身份；在线未缓存内容经读取完成后再交给外部应用，离线无缓存提供明确状态。历史页可对停止的挂载调用服务启动入口后重试。

## 停止诊断

`ShutdownWatcher` 单独订阅 `ShutdownChanged` 并读取 `GetShutdown`，核对任务身份和服务连接代次，不等待 Store-backed `GetOverview`。界面显示后台提供的结束传输、卸载、结束文件系统请求、保存本地状态等真实阶段。逾时表示尚未确认停止，不表示进程已被强杀或停止成功。旧后台不支持轻量接口时保留 Overview 的诊断兼容路径。

单挂载停止入口先区分“暂停同步（保留挂载，可恢复）”与“停止并卸载（结束挂载和服务）”，并说明不会删除缓存、草稿或远端文件。确认后调用 `StopMount`，按 `ShutdownWatcher` 阶段轮询至 `complete` 且确认卸载；成功时恢复页面按钮为可再次启动状态，失败或超时显示具体阻塞原因并打开诊断入口。轮询达到 90 秒仍未确认时显示超时和阻塞原因，提供复制诊断入口并保持界面可达；超时不等于停止成功，也不会强杀后台。停止全部同步并退出同样使用 90 秒总期限，超时后保留界面并提示查看诊断。

## 键盘

- `Ctrl+1`…`Ctrl+5` 切换当前视图标签页：挂载页对应概览／文件／同步历史／同步问题／挂载设置；全局视图下映射概览与同步历史，其它索引不切换到隐藏页。
- `Ctrl+,` 打开全局设置；`Ctrl+H` 打开同步历史；`Ctrl+Shift+A` 打开添加挂载；`Ctrl+Q` 弹出两种退出方式的菜单；`Ctrl+W` 在托盘可用时隐藏窗口，否则保留并提示；`F6` 在导航树与右侧页面之间切换焦点；导航树中 `Enter` 打开所选项。
- 新增按钮、列表、复选框与导航树均设置可读的 accessible name，快捷键使用窗口级 `QShortcut` 并带 `objectName`（`action_add_mount`、`action_show_settings`、`action_show_history`、`action_hide_window`、`action_exit_menu`、`action_focus_cycle`、`action_tab_1`…`action_tab_5`），不依赖鼠标。

## 验证范围

合成 GUI 回归覆盖同窗切换、任务配置和子进程环境隔离、迟到回复、单任务无响应、关闭／托盘丢失、独立停止查询、主题变化、全挂载表活动／问题列与行菜单、单挂载确认与真实停止阶段、超时／失败不强杀、通知 episode 与合并、无托盘时改走系统通知／系统通知不可用时静默、通知点击定位、freedesktop D-Bus 投递与回退、全局设置持久化与损坏回退、快捷键映射、导航 Enter、隐藏页不进入键盘路径、托盘图标与计数同源。单实例测试在 `dbus-run-session` 中运行；开发启动测试只运行无害合成程序，不启动同步后台。

```sh
GUI_PYTHON=/path/to/gui-venv/bin/python bash scripts/test-gui.sh
```

`scripts/test-gui.sh` 在 offscreen 环境逐个运行测试模块（含 `notification_tests`、`notification_dbus_tests`、`history_gui_tests`、`shutdown_diagnostic_tests`、`keyboard_gui_tests`、`window_transfer_tests`、`window_state_tests`）；脚本清除继承的 `DBUS_SESSION_BUS_ADDRESS`／`DBUS_SESSION_BUS_PID`，使通知投递测试使用注入的 fake 连接、绝不碰真实会话总线；`gui_instance_test` 在无会话总线且系统有 `dbus-run-session` 时自动套一层真实会话总线并设置 `DRIVE_NATIVE_GUI_REQUIRE_BUS=1`。测试不依赖真实托盘、D-Bus 或网络。渲染脚本 [`unified_gui_render.py`](../tests/unified_gui_render.py) 只使用合成挂载，不读取账号、访问 NAS 或连接后台。浅／深色截图只验证布局，不等同于 Mint/Cinnamon 托盘、通知和实机验收。完整包、真实 NAS、普通目录全量同步及其他最终门禁仍按仓库验收记录执行。
