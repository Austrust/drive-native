# 统一主窗口与托盘（issue #2）

当前开发实现将多挂载管理收敛到同一个主窗口，并通过 schema24 的历史记录提供持久活动查询。当前传输与目录发现不等于已完成同步；实现及独立验证状态见 [#5/#2 报告](../../docs/FIX_5_2_REPORT.md)。

## 界面与隔离

- `MountManager` 展示所有挂载；任务详情是按需创建的嵌入页。切换挂载复用页面，不启动新的 GUI 进程。添加挂载仍使用现有配置向导。
- 每页显式绑定配置 slot、D-Bus 服务、systemd unit 和向导；保存、归档、恢复配置均使用该 slot。开发启动也通过独立子进程环境指定实例，不修改 GUI 进程的环境变量。
- 总览与当前活动查询按任务合并在途请求。某任务无响应不会等待后再刷新其他任务。外部配置替换时丢弃旧页面、旧服务对象及迟到回复。本页“更换目录”成功归档配置后，只保留自身拥有的短暂配置空缺；向导取消恢复或确认新任务后保留该页，服务状态重新核对，不把外部删除／替换视为本页事务。
- 隐藏任务页沿用已有懒加载，不展开文件列表就不查询目录。证书、缓存、问题和带宽继续复用各任务的对话框。
- 字体、按钮、列表及明暗配色复用同一个主题函数。系统配色变化同步更新嵌入页。

## 托盘与激活

左键切换活动面板；右键提供主窗口、当前活动与最近历史、各挂载文件夹、单挂载及全体暂停／恢复和两种退出方式。当前活动仍展示在途传输，持久完成记录通过独立历史 IPC 查询。

关闭主窗口时，有托盘则隐藏界面；无托盘则退出界面，后台保持运行。运行中托盘消失会重新显示主窗口。活动面板使用实际托盘位置或鼠标位置，并限制在所在屏幕内。桌面不支持左键激活时仍可走右键菜单。

GUI 使用会话 D-Bus 服务按配置根隔离单实例。再次启动激活同一窗口，并可定位 `--task` 指定的挂载。启动阶段的激活请求暂存，窗口就绪后执行最后一次请求。会话 D-Bus 不可用时保留可见窗口，不宣称该环境具备单实例保证。

全体恢复只恢复本轮全体暂停所记录的任务，保留用户此前的单挂载暂停。停止全部同步并退出使用既有正常关闭流程。历史行绑定所属服务和记录 id，打开前重新解析当前文件身份；在线未缓存内容经读取完成后再交给外部应用，离线无缓存提供明确状态。

## 停止诊断

`ShutdownWatcher` 单独订阅 `ShutdownChanged` 并读取 `GetShutdown`，核对任务身份和服务连接代次，不等待 Store-backed `GetOverview`。界面显示后台提供的结束传输、卸载、结束文件系统请求、保存本地状态等真实阶段。逾时表示尚未确认停止，不表示进程已被强杀或停止成功。旧后台不支持轻量接口时保留 Overview 的诊断兼容路径。

## 验证范围

合成 GUI 回归覆盖同窗切换、任务配置和子进程环境隔离、迟到回复、单任务无响应、关闭／托盘丢失、独立停止查询及主题变化。单实例测试使用真实独立会话 D-Bus 和第二个 GUI 子进程；开发启动测试只运行无害合成程序，不启动同步后台。

```sh
GUI_PYTHON=/path/to/gui-venv/bin/python dbus-run-session -- bash scripts/test-gui.sh
```

渲染脚本 [`unified_gui_render.py`](../tests/unified_gui_render.py) 只使用合成挂载，不读取账号、访问 NAS 或连接后台。浅／深色截图只验证布局，不等同于 Mint/Cinnamon 托盘、通知和实机验收。完整包、真实 NAS、普通目录全量同步及其他最终门禁仍按仓库验收记录执行。
